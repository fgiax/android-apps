## Kotlin Multiplatform (KMP)

Многие компании используют KMP не как «замену Android и iOS», а как способ иметь одну кодовую базу для логики приложения, оставляя интерфейс полностью нативным для каждой платформы.

### Kotlin Multiplatform quickstart

>[!note] Tutorial адоптирован мною `@fgiax` для Termux!

In this tutorial, you'll learn how to build and run a simple Kotlin Multiplatform app with a Compose Multiplatform UI.

1. Install `gradle`, `openjdk`,

2. `plugins nvim`

3. Set up the environment

Add the following command to your .profile or .zprofile:

```bash
export ANDROID_HOME=~/Library/Android/sdk
```
